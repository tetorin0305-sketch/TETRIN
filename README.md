# TETRIN
Fan-Made Tetris game
ブラウザで遊べるオリジナルテトリスゲームです。

## 特徴
- 「次の5個」を見通して戦略的に積むHOLDシステム
- 3つのモードで遊べます
  - **マラソン**：長時間プレイでハイスコアを目指す
  - **40ライン**：40ライン消去までのタイムアタック
  - **4列REN**：4列消しでRENを維持し続ける

## 遊び方
- **移動**：← →  
- **回転**：↑  
- **下に落とす**：↓  
- **HOLD**：C  

## プレイ方法
ブラウザで [こちら](https://ユーザー名.github.io/TETRIN/) を開くだけで遊べます

## 注意
- PC キーボード推奨
- スマホには対応していません
